# References and Resource Notes

## Official workshop reference

- Number Theory and Cryptography Workshop: https://github.com/mnp-club/Number_Theory_and_Cryptography_Workshop

## Core topics identified from the reference

- number theory foundations
- divisibility and prime numbers
- Euclidean algorithm and GCD
- modular arithmetic
- Euler's totient function
- Fermat's little theorem
- public-key cryptography and RSA
- classical cryptographic reasoning

## Notes

The reference repository gives an introductory workshop structure rather than a deep formal textbook. This project therefore focuses on the core mathematical tools and the RSA-based cryptography that most clearly links the theory to practical implementation.
